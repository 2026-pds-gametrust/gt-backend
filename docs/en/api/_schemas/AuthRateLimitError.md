# Schema: AuthRateLimitError

**OpenAPI schema:** `AuthRateLimitError`

| Field | Type | Required | Description |
|-------|------|-------------|----------|
| `message` | string | yes | Generic throttle message with no email, CPF, or RESOURCE_CONFLICT |

**Example:**

```json
{
  "message": "Too many requests, please try again later."
}
```
