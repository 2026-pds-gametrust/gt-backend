# Glossary EN ↔ PT

Normative identifiers are **English**. This page is a short extract for published docs. Full table and DEC-080: [docs/architecture/08-glossary.md](../../architecture/08-glossary.md). Portuguese: [pt-BR](../../pt-BR/architecture/glossary.md).

| EN (code / API) | PT (product) | Notes |
|-----------------|--------------|-------|
| Listing | Anúncio / oferta (unidade) | One seller unit; not the catalog model |
| Product | Produto / modelo | Canonical catalog entry |
| Category | Categoria | Taxonomy node |
| Service (taxonomy) | Serviço | Marketplace service node — not a domain `*Service` class |
| Seal | Selo | Verification badge; never show without granted status |
| Verification case | Caso de verificação | Review unit |
| Evidence | Evidência | Restricted media + checklist |
| TrustScore | TrustScore / pontuação de confiança | Explainable score + reasons |
| Seller level | Nível do vendedor | Progression badge |
| User | Usuário / conta | No password on the domain User |
| Profile | Perfil | Display, addresses, Meu Setup |
| Favorite | Favorito | Saved product or listing |
| Synonym | Sinônimo | Alias → exactly one category or service |

Module slugs stay in English in both locales (`listings`, `trust`, …).
