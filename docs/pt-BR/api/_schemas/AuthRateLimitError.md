# Schema: AuthRateLimitError

**Schema OpenAPI:** `AuthRateLimitError`

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|----------|
| `message` | string | sim | Generic throttle message with no email, CPF, or RESOURCE_CONFLICT |

**Exemplo:**

```json
{
  "message": "Too many requests, please try again later."
}
```
