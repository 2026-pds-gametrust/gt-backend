# Glossário EN ↔ PT

Identificadores normativos são **inglês**. Extrato curto para a doc publicada. Tabela completa e DEC-080: [docs/architecture/08-glossary.md](../../architecture/08-glossary.md). Inglês: [en](../../en/architecture/glossary.md).

| EN (código / API) | PT (produto) | Notas |
|-------------------|--------------|-------|
| Listing | Anúncio / oferta (unidade) | Unidade do vendedor; não é o modelo de catálogo |
| Product | Produto / modelo | Entrada canônica do catálogo |
| Category | Categoria | Nó de taxonomia |
| Service (taxonomy) | Serviço | Nó de serviço do marketplace — não é a classe `*Service` |
| Seal | Selo | Badge de verificação; nunca exibir sem status concedido |
| Verification case | Caso de verificação | Unidade de revisão |
| Evidence | Evidência | Mídia restrita + checklist |
| TrustScore | TrustScore / pontuação de confiança | Score explicável + motivos |
| Seller level | Nível do vendedor | Badge de progressão |
| User | Usuário / conta | Sem senha no User de domínio |
| Profile | Perfil | Apresentação, endereços, Meu Setup |
| Favorite | Favorito | Produto ou listing salvo |
| Synonym | Sinônimo | Alias → exatamente uma categoria ou serviço |

Slugs de módulo ficam em inglês nos dois locales (`listings`, `trust`, …).
